Shorts Uploader Privacy Policy

Last updated 11 November 2026

Who uses this app

Shorts Uploader is a personal tool its owner uses to post their own videos to their own TikTok accounts. It has no other users and does not collect data from anyone else.

What data the app handles

  • TikTok sign-in tokens (access and refresh tokens) for each connected account, so videos can be uploaded.
  • Basic account info from TikTok: the account's open ID, display name and username, used to label which account a video goes to.
  • Post settings TikTok returns before posting, such as the allowed privacy levels and maximum video length.
  • A post log: the file name, caption, publish ID and link of each video posted.

Where it is stored

Everything is stored only on the owner's own computer, in a local file readable only by the owner's user account. Nothing is sent to any server other than TikTok's official API.

What the app does not do

  • It does not sell, share or rent any data.
  • It does not read followers, messages, comments, likes or viewing history.
  • It does not use analytics, advertising or tracking.

Keeping and deleting data

Tokens are kept until the account is disconnected. To revoke access, open the TikTok app and go to Settings and privacy → Security → Manage app permissions. Deleting the local config file removes all stored tokens.

TikTok

Data held by TikTok is covered by TikTok's Privacy Policy.
